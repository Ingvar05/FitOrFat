# FitOrFat

Приложение справочник калорийности продуктов и блюд, а также дневник питания.

# Стек

1) Bak-end: ASP.NET (.NET 10) EFCore
2) Front-end: Bootstrap 5 + custom CSS elements
3) Database: SQLite

# Функционал

1) Справочник КБЖУ продуктов питания и/или приготовленных блюд
2) Конструктор и пересчёт КБЖУ собственных блюд созданных авторизованным пользователем
3) Добавление продуктов авторизованным пользователем
4) Дневник питания авторизованного пользователя со стандартным функционалом (добавление позиций, удаление, правки)
5) Дневник веса авторизованного пользователя
6) Профиль пользователя
